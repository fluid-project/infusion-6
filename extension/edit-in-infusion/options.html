Edit in Infusion

Edits are committed to the repository named by each page's linkage record, through the GitHub API. Until signing in through GitHub is supported, give a fine-grained personal access token with Contents: read and write on the repositories you edit. It is kept in this browser's extension storage and is never visible to the pages you edit.

Sites

The extension does nothing on a site until you click its button there. Once you allow it access to a site, every page of the site shows the edits you have made but not yet seen published. Forgetting a site withdraws that access; the edits you hold for it are kept.
